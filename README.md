# Metamorphosis

Metamorphosis takes you through the life cycle of a butterfly, from caterpillar to chrysalis, from chrysalis to butterfly, and from butterfly to death. Each new stage in life takes on different mechanics. 

Made using Box2D and SFML

Each level uses a combination of WASD or Arrow Key controls. Escape to pause. Space or Enter to select items within the menu. Backspace to skip to the next level.

**IMPORTANT NOTE:** Only run using x86!!!

Players must avoid branches to make it to the ground while falling.

## Level 3 - Hatchling
<img width="2553" height="1478" alt="image" src="https://github.com/user-attachments/assets/91bf76be-5e22-4621-8097-03a6b13d60bf" />
